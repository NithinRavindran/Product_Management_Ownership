# User Story Examples

## Format
As a **[user]**, I want **[capability]**, so that **[outcome]**.

## Example: booking status
As a traveller, I want to see the current status of my booking, so that I understand whether my reservation is confirmed.

## Example: appointment scheduling
As a patient, I want to view available appointment slots, so that I can choose a suitable time.

## Story quality checklist
- User and need are clear.
- Outcome is meaningful.
- Story is small enough to estimate and deliver.
- Dependencies and assumptions are visible.
- Acceptance criteria are testable.
- Edge cases and permissions are considered.
