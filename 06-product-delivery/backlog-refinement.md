# Backlog Refinement Checklist

- [ ] Problem and user value are clear.
- [ ] Story is sized appropriately.
- [ ] Acceptance criteria are testable.
- [ ] UX / content dependencies are identified.
- [ ] API / data / platform dependencies are identified.
- [ ] Security, privacy and accessibility have been considered.
- [ ] Analytics requirements are documented.
- [ ] Edge cases and failure paths are discussed.
- [ ] Priority and rationale are visible.
- [ ] Team questions are resolved or tracked.
