# Release Readiness Checklist

## Product and business
- [ ] Scope and release notes approved.
- [ ] Stakeholders and support teams informed.
- [ ] User documentation / help content ready.

## Quality and operations
- [ ] Critical test scenarios pass.
- [ ] Monitoring and alerts configured.
- [ ] Rollback / recovery plan documented.
- [ ] Operational ownership confirmed.

## Security and compliance
- [ ] Security and privacy review completed as applicable.
- [ ] Access and permissions verified.
- [ ] Data migration and retention checked.
