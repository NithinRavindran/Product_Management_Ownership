# Product Metrics Catalogue

| Metric | Definition | Useful segmentation | Caveat |
|---|---|---|---|
| Activation rate | Share of eligible new users completing a defined activation event | Channel, cohort, segment | Define activation and eligibility |
| Conversion rate | Share progressing from a defined funnel step to the next / end | Device, channel, segment | Use consistent denominators |
| Feature adoption | Eligible active users using a feature in a period | Feature, cohort, role | Distinguish trial from repeated use |
| Retention | Cohort users returning / completing a value event in a later period | Signup cohort, segment | Define return event and window |
| Churn | Users / customers meeting a documented churn definition | Segment, plan | Logo and revenue churn differ |
| DAU / WAU / MAU | Unique active users in daily / weekly / monthly windows | Segment, platform | Define meaningful activity |
| Time to value | Time from a defined start to first realised value event | Segment, channel | Handle outliers and incomplete data |
| Reliability | Successful transactions divided by eligible attempts | Integration, service, version | Classify expected failures |

For every KPI, record owner, source event, formula, time window, exclusions, refresh cadence and data-quality checks.
